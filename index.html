TFM Chat Digest

A private tool that brings Google Chat updates into an internal daily digest.

How it works

The tool reads Google Chat conversations accessible to the authorised Google account and creates a digest in Google Docs. The Funky Monkeys uses this digest with ChatGPT to prepare internal briefings and action lists.

The tool does not send, edit or delete Google Chat messages.

Private use, public information

This website explains the tool and its data practices. It does not provide access to conversations or digests. The tool is intended for authorised internal use only.
